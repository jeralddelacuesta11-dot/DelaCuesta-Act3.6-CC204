PROJECT FILES
-------------
1. binary_tree_dela_cuesta.py
   Original Assessment 3.4 binary tree using all 10 letters
   of DELACUESTA. Displays BFS and DFS (Preorder).

2. graph_dela_cuesta.py
   Original Assessment 3.4 undirected graph using the distinct
   letters in DELACUESTA. Displays BFS and DFS.

3. dfs_methods_in_tree_dela_cuesta.py
   Assessment 3.6. Uses the same binary-tree arrangement as
   Assessment 3.4 and displays all three DFS methods:
   Preorder, Inorder, and Postorder.

HOW TO RUN IN PYCHARM
---------------------
1. Extract the ZIP file.
2. Open the extracted project folder in PyCharm.
3. Open the Python file you want to run.
4. Click the green Run button.

No external packages are required.

ASSESSMENT 3.6 EXPECTED DFS OUTPUT
----------------------------------
Preorder  : D - E - A - S - T - C - A - L - U - E
Inorder   : S - A - T - E - A - C - D - U - L - E
Postorder : S - T - A - A - C - E - U - E - L - D

NOTE
----
Repeated letters are separate nodes because each letter position
in the surname is represented in the binary tree.
